Vistara має REST API для вивантаження даних і керування звітами.

## Як отримати ключ

1. Відкрийте «Налаштування» → «Для розробників» → «API-ключі».
2. Натисніть «Створити ключ», задайте назву й права: читання або читання та запис.
3. Скопіюйте ключ одразу: пізніше його не буде видно.

Передавайте ключ у заголовку `Authorization: Bearer <ключ>`.

## Ліміти запитів

Для одного ключа діє ліміт 100 запитів за хвилину. Якщо ви перевищили його, API відповідає помилкою 429 Too Many Requests із заголовком `Retry-After`: у ньому кількість секунд до наступної спроби. Вмикайте повтор із затримкою, що зростає, і не надсилайте запити паралельно без потреби.

## Безпека

Якщо ключ потрапив у сторонні руки, негайно відкличте його в тому самому розділі й створіть новий.
